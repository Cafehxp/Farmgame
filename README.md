# Jogo de Terminal em C

Este é um protótipo de um jogo de terminal bem simples, desenvolvido em linguagem C.

Estou fazendo este projeto para aprender enquanto desenvolvo. Com certeza existem maneiras mais eficientes de fazer várias coisas, mas, como ainda estou aprendendo, só de conseguir fazer funcionar já tá ótimo.

Por enquanto, o jogo conta apenas com um **menu inicial**.
